# 淘金币助手 APK（无障碍首版）

电脑脚本逻辑的手机版：授权无障碍后，在本机点淘宝完成淘金币浏览任务。

## 环境

本机当前没有 Android SDK / JDK 17，需要用 **Android Studio** 打开本目录编译：

1. 安装 [Android Studio](https://developer.android.com/studio)（自带 JDK 17 和 SDK）
2. File → Open → 选仓库里的 `android/` 文件夹
3. 等 Gradle Sync 结束
4. 手机开 USB 调试，点 Run；或 Build → Build APK(s)

生成的包一般在 `android/app/build/outputs/apk/debug/app-debug.apk`。

## 真机使用

1. 安装 APK
2. **授权无障碍** → 打开「淘金币助手」
3. **授权悬浮窗** → 顶部控制条：**展开/收起**日志、**停止/继续**
4. **任务设置** → 编辑跳过关键词、目标数量（保存后不用重装）
5. 点 **开始跑任务**（会自动尝试拉起淘宝）

## 任务设置

主界面 **「任务设置（跳过 / 目标数量）」**：

- **跳过关键词**：每行一个，任务名包含即跳过
- **本轮目标数量**：完成多少个任务闭环
- **保存设置** 后立即写入本机，下次「开始/继续」生效
- **恢复默认** 可还原为内置 `config.yaml` 列表

## 首版已照搬
- 进列表（签到领金币 / 赚更多金币只点一次）
- 选「去完成/去逛逛」，屏蔽词、已点过跳过
- 秒返 / 趣味课堂 / 搜一搜点提示词
- 先滑再认「已得」，回到列表才 +1
- 列表上不点「关闭」

## 首版限制

- 搜一搜若没有提示词，不会调输入法打「笔记本电脑」
- 淘宝 H5 节点因机型可能比 uiautomator2 更少，任务名仍可能变成「未命名」
- 部分系统要在无障碍页再开「允许显示在其他应用上层」才滑动稳定
