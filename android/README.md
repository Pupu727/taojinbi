# 淘金助手

自动完成淘宝「淘金币」浏览类任务的 Android 应用。开启无障碍后，由本机代为点击、滑动，减少重复手动操作。

**本软件仅供学习交流使用。**

## 能做什么

- 自动进入淘金币任务列表（含签到入口）
- 按白名单 / 黑名单筛选任务，点击「去完成」「去逛逛」
- 浏览至「已得」后返回列表并计数
- 支持秒返、趣味课堂、搜一搜等常见任务流程
- 顶部悬浮条可展开运行日志，随时停止或继续

## 使用前准备

1. 用 Android Studio 打开本目录，编译安装到手机（或安装已打好的 APK）
2. 开启本应用的 **无障碍服务**
3. 授权 **悬浮窗**（用于运行日志）
4. 在「任务设置」里确认白名单、黑名单与本轮目标数量
5. 点 **开始跑任务**（会尝试自动打开淘宝）

## 任务设置

- **放行（白名单）**：任务名包含这些词时强制去做
- **跳过（黑名单）**：任务名包含这些词时跳过
- **目标数量**：本轮要完成多少个「点进 → 做完 → 回列表」闭环
- 保存后立即生效；「恢复默认」可还原为应用内置配置

## 编译说明

1. 安装 [Android Studio](https://developer.android.com/studio)
2. File → Open → 选择本目录
3. Gradle Sync 完成后 Run，或 Build → Build APK(s)
4. Debug 包路径：`app/build/outputs/apk/debug/app-debug.apk`

## 使用注意

- 请仅在本人手机、本人账号上使用
- 部分机型需在无障碍相关设置中允许「显示在其他应用上层」，滑动才更稳定
- 淘宝界面改版后，个别任务识别可能受影响，可在设置里调整关键词
